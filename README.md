#  Centro Veterinario Perú

Este proyecto es una página web informativa para el **Centro Veterinario Perú**, diseñada con el objetivo de mostrar los servicios, misión, visión y datos de contacto de la clínica.

---

##  Descripción
La página incluye las siguientes secciones:
- **Inicio**: Bienvenida y presentación del centro.
- **Servicios**: Lista de servicios veterinarios con imágenes representativas.
- **Nosotros**: Historia, misión, visión y valores del centro.
- **Contacto**: Información de contacto (teléfono, correo, dirección).

---

##  Tecnologías utilizadas
- **HTML5** → Estructura del sitio web.  
- **CSS3** → Estilos y diseño visual.  
- **Git & GitHub** → Control de versiones y repositorio remoto.  
- **Visual Studio Code** → Editor de código.
